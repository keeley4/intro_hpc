# Not a Big Laptop

An interactive first look at supercomputing for people with no background, told as one story: your simulation is too big for your laptop.

1. **Why you need a supercomputer.** Sharpen a storm forecast map and see the work multiply.

2. **Hire helpers.** Add processor cores. See why separate jobs speed up perfectly and one giant job does not.
3. **Helpers have to talk.** Cut a map into patches and watch the borders eat the gains. Try a bigger map.
4. **Where you sit matters.** The same job, seated in one room or spread across rooms, with a shared hallway.
5. **Your turn.** Meet a 30-hour deadline inside a 3,000 core-hour budget.

All numbers are illustrative teaching values, not benchmarks of any system.

## Run it

Open `index.html` in a browser. No build step.

## Host it

Enable GitHub Pages on the `main` branch, root folder.
