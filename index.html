ICRN: notebooks that run at NCSA

Illinois Computes Research Notebooks (ICRN) gives you Jupyter, RStudio or VS Code in a web browser. There is nothing to install, and your code keeps running after you close your laptop. Each notebook gets one core, so it runs at about the speed of your laptop.

The cost of communication

What this means for you
  • Adding cores does not always make a job faster. On small problems, the time spent exchanging data can cancel out the gain.
  • Before you request a lot of cores, time a few short runs (see Sizing a job).

ClusterBackground: good to know

Where your job runs on the cluster

Cores on the same node share memory, so passing data between them is fast. Cores on different nodes pass data over the network, which all running jobs share.

Try: switch between the two placements

What this means for you
  • Slurm picks your nodes, and its defaults are usually fine.
  • If your job fits on one node, request one node (--nodes=1).
  • If the same job runs slower on a different day, placement and network traffic are common causes. Time a few runs before drawing conclusions.

Submitting a batch job

On a cluster you don’t run programs directly. You write a short script that says what you need, submit it to the scheduler, and it starts your job when enough nodes are free.
